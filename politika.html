2. Какие данные обрабатываются

Сайт построен так, что не собирает и не хранит персональные данные посетителей на своих серверах. У Сайта нет форм, отправляющих сведения оператору, и нет базы данных посетителей.

Обрабатываются только следующие сведения:

  • Обезличенные данные о посещении — с помощью сервиса веб-аналитики: тип устройства и браузера, разрешение экрана, источник перехода, просмотренные страницы, время на сайте, приблизительный город. Эти сведения не позволяют определить личность посетителя.
  • Файлы cookie — небольшие технические файлы, которые сохраняются в браузере. Подробнее в разделе 6.
  • Данные, которые посетитель вводит сам — в помощнике «Молли» и в конструкторе приглашений. Эти сведения обрабатываются непосредственно в браузере посетителя и оператору не передаются (см. раздел 4).

3. Цели обработки

  • обеспечение работы Сайта и его отдельных разделов;
  • улучшение содержания Сайта на основе обезличенной статистики посещений;
  • сохранение пользовательских настроек, чтобы не показывать повторно уже закрытые уведомления.

Обезличенные данные обрабатываются на основании законного интереса оператора в поддержании работоспособности и развитии Сайта. Файлы cookie, не являющиеся строго необходимыми, обрабатываются с согласия посетителя, выражаемого через уведомление при первом посещении.

4. Как работают интерактивные разделы Сайта

Помощник «Молли». Диалог с помощником целиком выполняется в браузере посетителя. Введённый текст, а также сведения, указанные при оформлении заявки на бронирование (дата, число гостей, имя), никуда не отправляются: они используются только для того, чтобы составить готовое сообщение, которое посетитель по своему усмотрению передаёт заведению по телефону, во ВКонтакте или через систему бронирования. После закрытия страницы эти сведения не сохраняются.

Конструктор приглашений. Сведения, введённые в конструкторе (повод, дата, время, имя, текст сообщения), передаются исключительно через адрес созданной ссылки и на серверах оператора не сохраняются. Ссылку распространяет сам создатель приглашения, и содержание ссылки доступно каждому, кто её получит. Оператор рекомендует не указывать в приглашении сведения, которые не предназначены для посторонних.

5. Передача данных третьим лицам

Оператор не продаёт и не передаёт персональные данные третьим лицам, за исключением случаев, прямо предусмотренных законом. Вместе с тем на Сайте используются сторонние сервисы, обрабатывающие данные по собственным правилам:

  • Сервис веб-аналитики — сбор обезличенной статистики посещений.
  • Система бронирования RestoPlace — бронирование столов. Переход в неё осуществляется по ссылке; данные посетитель вводит уже на стороне этого сервиса, и их обработка регулируется его правилами.
  • Сервисы карт — отображение схемы проезда.
  • Социальные сети и сервисы продажи билетов — переходы по ссылкам с Сайта.

Переходя на сторонние ресурсы, посетитель принимает условия их политик конфиденциальности. Оператор не несёт ответственности за обработку данных сторонними сервисами.

6. Файлы cookie

Cookie — небольшие текстовые файлы, которые сохраняются в браузере при посещении Сайта. Сайт использует:

  • Технически необходимые — сохраняют выбор посетителя, например факт закрытия уведомления о cookie. Без них Сайт работает некорректно, поэтому они используются всегда.
  • Аналитические — позволяют сервису веб-аналитики отличать новых посетителей от вернувшихся и считать обезличенную статистику.

Посетитель вправе в любой момент отключить или удалить файлы cookie в настройках своего браузера. При этом отдельные разделы Сайта могут работать некорректно.
